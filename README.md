# Pizza Rush

Pizza Rush is a native portrait iPhone arcade cooking game. Players keep a visible, capacity-limited kitchen moving through Preparation → Oven → Cutting → Dispatch while managing patience, perfect bake timing, combos, stars, upgrades, and durable local progression.

## Product

- iOS 17+
- SwiftUI + SpriteKit
- Swift 6 strict concurrency
- SwiftData persistence
- AVAudioEngine procedural stereo sound
- StoreKit 2 non-consumable Remove Ads
- Google Mobile Ads + UMP with non-personalized treatment
- Game Center nonblocking integration
- 20 World 1 levels and six recipes

## Release policy

App Store binaries are archived, signed, validated, and uploaded through Xcode Cloud. Local builds are used only for development, tests, simulator inspection, and deterministic screenshots. Release after App Review approval is manual.
