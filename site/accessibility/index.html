Accessibility

Pizza Rush is designed so the production line is understandable through text, icons, shape, position, and accessible actions—not only color, sound, precise gestures, or fast motion.

Assist Mode

Assist Mode enlarges gameplay targets, extends customer patience, widens the perfect-bake window, and slows order pressure. Progression and rewards remain unchanged.

Text and layout

SwiftUI menus and results support larger Dynamic Type. At accessibility XXXL, result metrics and actions reflow into a scrollable single-column layout.

Color and motion

Bake phases use explicit text and dot, checkmark, star, exclamation, and smoke cues in addition to color. Reduce Motion removes nonessential travel, bounce, scale, pulse, and particle effects while keeping state changes visible.

Screen-reader and voice input status

Menus, orders, timers, station state, ingredients, production actions, results, upgrades, and support controls expose named accessibility elements and button equivalents. Human VoiceOver and Voice Control review on the production-signed hosted build is still pending, so no App Store support declaration for those features is claimed yet.

Feedback

To report an accessibility issue, use the support page and include the iPhone model, iOS version, assistive technology, and the screen or action involved.
